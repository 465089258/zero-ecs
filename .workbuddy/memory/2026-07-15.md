### 游戏玩法
- 射手在左侧(70,320)，自动向右发射子弹
- 墙壁在 x=210，HP=500，被僵尸打破则失败
- 僵尸从右侧(920)生成，向左移动攻击墙壁
- 击杀僵尸获得经验球 → 收集 → XP 满 → 升级
- 升级时随机 3 选 1：攻击力/攻速/散射/分裂/弹射/连射/暴击
- 按 1/2/3 选择升级，按 R 重新开始

### 修复：射手瞄准最近敌人
- `shooterFireSystem` 改为接受 `ZombieQuery` 参数
- 新增 `findNearestZombieAngle()` 辅助函数，遍历所有僵尸找最近目标
- 子弹基准角度从固定 `0`（水平向右）改为指向最近僵尸的方向
- 无僵尸时默认仍向右发射（`closestAngle` 初始值 0）
- 散射/连射的偏移基于该基准角度展开

### 优化：四种游戏机制调整
1. **僵尸渐进生成**：波次间隔从 8s 随 wave 逐减 (min 3s)，生成延迟从 0.3-0.8s 逐减至 0.1-0.3s。上限 80 只。
2. **连射间隔**：Shooter 组件新增 `burstCooldown`(F32) + `burstLeft`(U8)。首组散射即时发射，后续 burst 以 `fireInterval/burstCount` 间隔逐组发射。
3. **弹射机制**：子弹在地图边界反射（消耗 ricochetCount），命中僵尸时若 ricochetCount>0 则改变方向弹向最近敌人（ricochetCount--），若归零则消失。
4. **分裂不变**：命中时在随机方向生成 N 个新子弹。

### 分阶段波次 + 新升级
- **分阶段生成**：开局 base=3 只/波，每 5 波触发 boss 波（×2 数量），boss 波结束后 base+2
- **新增升级**（池从 7→9 种）：`FlatDamage`（伤害增加，flat +8/级）、`DamageMultiplier`（伤害总增，×1.15/级）
- `spawnShooter` 伤害公式：`(baseDamage + flatDamage) * damageMultiplier`
- `statisticsSystem` 新增 `GameConfigResource` 参数，末尾调用 `applyBaseGrowth`
- `restartSystem` 重置新增字段 + `pendingBaseGrowth`

### XP 曲线 + 僵尸成长曲线优化
- **XP 公式**：从线性 `50 + level×25` 改为二次 `50 + level×35 + level²×3`
- **僵尸属性**：从线性波次成长改为二次曲线
  - HP: `60 + wave² × 2`（wave 1=62, wave 10=260, wave 20=860）
  - Speed: `55 + wave×2 + wave²×0.3`
  - XP掉落: `20 + wave² × 3`
- Lv.1→2 需 88 XP，Lv.10→11 需 730 XP，Lv.20→21 需 1953 XP

### 伤害漂浮文字 + 难度再平衡
- 新增 `DamageText` 组件（value, lifetime, floatY）+ `DamageTextQuery`
- `bulletZombieCollisionSystem` 命中时 spawn 伤害数字实体
- `damageTextUpdateSystem`：漂浮文字持续 0.7s 向上浮动 40px，到时消除
- `RendererService.drawDamageTexts`：黄色带描边，透明度随剩余 life 渐变
- **XP 曲线更陡**：`50 + level×45 + level²×5`（Lv.10→11 需 1000 XP，Lv.20→21 需 2950 XP）
- **僵尸更猛**：
  - XP掉落降至 `20 + wave²×1.5`
  - 速度提至 `55 + wave×3 + wave²×0.5`
  - 对墙伤害从固定 15 改为 `15 + wave×0.5`（随波次增长）

### 攻击/攻速/暴击百分比化
- **攻速**：基础 2s，公式 `2 / (1 + bonus)`，每级 bonus+0.15（Lv.1=2s, Lv.5=1.25s, Lv.10=0.85s）
- **攻击力**：基础 5，公式 `5 * (1 + level*0.15)`，每级 +15%（Lv.1=5, Lv.5=8, Lv.10=11.75）
- **暴击拆分**：Crit 拆为 CritChance(暴击提高) + CritDamage(暴击伤害)
  - CritChance: `0.05 * (1 + bonus)`, bonus 每级 +0.05
  - CritDamage: `2.0 * (1 + bonus)`, bonus 每级 +0.15
- 最终伤害：`((5*(1+damageLv*0.15) + flatDmg) * dmgMultiplier) * (暴击时 *critMult)`
- 升级池从 9→10 种

### 波次尸潮 + 进度条 UI
- **GameState** 新增 `inHorde` + `waveZombieTotal` 字段
- **尸潮机制**：每波僵尸全部清空后触发（spawnQueue=0 && zombies=0），瞬间生成 `base×3 + wave×3` 只尸潮僵尸（HP 按 wave+2 计算，更硬）
- 尸潮清空后自动开始下一波倒计时
- **Canvas 顶部波次条**：显示 `WAVE N` + 绿色进度条（杀怪比例），尸潮时变红色 + "尸潮爆发!" 文字
- restartSystem 重置新增字段
