本文在现有飞剑运动、单剑属性、灵力轮换和四种战斗方式之上，定义局内构筑、生存恢复、
敌潮节奏和首领验证目标。本文只约束飞剑肉鸽示例，不把装备、吸血、回血或敌潮规则下沉
到 Zero ECS 三层公共库。

## 1. 设计目标

下一阶段需要把飞剑示例从“具有多个技能效果的战斗演示”推进为一局可重复构筑的游戏：

```text
获得属性不同的飞剑
→ 由剑夹决定持有量、神识决定并发量
→ 在分散、集火、剑阵和身剑合一之间管理资源
→ 通过剑器、御剑术、剑阵、剑意和生存能力形成构筑
→ 应对逐步教学四种战斗方式的敌潮
→ 第 8 分钟击败首领或角色身死
```

本阶段不加入永久货币、局外天赋、随机房间和复杂锻造。获得飞剑、选择升级、完成单局
必须先形成闭环。

## 2. 四种战斗方式与资源循环

| 方式 | 定位 | 主要资源 | 优势 | 代价 |
| --- | --- | --- | --- | --- |
| 分散御剑 | 常态输出与恢复窗口 | 单剑灵力 | 自动索敌、持续输出、允许法力恢复 | 爆发较低、目标分散 |
| 集火御剑 | 主动直线爆发 | 一次消耗全部法力 | 贯穿路径、法力越多伤害越高 | 施放后进入法力真空 |
| 剑阵 | 范围控制 | 持续消耗人物法力与单剑灵力 | 清理密集敌群、维持火寒效果 | 压缩下一次集火的蓄力空间 |
| 身剑合一 | 位移、破阵与追击 | 持续消耗体力 | 穿过包围、追击精英、重新站位 | 有聚剑前摇，转向受限 |

推荐的基础循环是：

```text
分散作战并恢复法力
→ 开启剑阵处理密集敌潮
→ 退出剑阵重新蓄积法力
→ 满法力或高法力集火精英
→ 身剑合一脱离包围或追击
→ 回到分散并轮换灵力耗尽的飞剑
```

分散御剑不是低级姿态，而是整个资源循环的常态阶段。集火不得拥有独立冷却并绕过法力
循环；剑阵不能在不付出法力的情况下永久维持；身剑合一不得取代普通移动。

## 3. 飞剑装备构筑

### 3.1 基础剑器倾向

第一阶段使用四种属性模板形成可感知差异，不立即扩展为任意词缀系统：

| 模板 | 伤害 | 攻击间隔 | 飞行 | 灵力 | 主要方向 |
| --- | --- | --- | --- | --- | --- |
| 轻灵剑 | 较低且稳定 | 短 | 快 | 消耗低、恢复快 | 分散持续输出 |
| 重锋剑 | 高且稳定 | 长 | 较慢 | 单次消耗高 | 集火贯穿 |
| 灵枢剑 | 中等 | 中等 | 中等 | 上限与恢复高 | 剑阵和持久战 |
| 爆发剑 | 上下限波动大 | 较长 | 快速冲刺 | 消耗高 | 高法力集火 |

模板只决定属性生成区间，不把飞剑锁定为职业。后续品质、五行和词缀必须建立在同一份
单剑属性事实之上。

### 3.2 获得与替换

获得飞剑 Offer 至少展示：

- 伤害上下限和期望单次伤害；
- 攻击间隔；
- 最大飞行速度与加速度；
- 灵力上限、恢复速度；
- 分散与集火的单次灵力消耗；
- 推荐战斗方式。

剑夹未满时直接收入。剑夹已满时进入替换选择，允许放弃新剑或替换一把现有剑。第一阶段
不加入分解货币。替换完成后由控制权归并 System 根据神识和稳定槽位重新分配受控与后备
Tag，表现层不得自行决定哪把剑出战。

### 3.3 剑夹与神识

剑夹容量增加持久作战能力：

- 增加后备飞剑；
- 灵力耗尽后拥有更多可轮换候补；
- 不直接提高同一时刻的飞剑数量。

神识增加即时并发能力：

- 增加分散、集火、剑阵和身剑合一的参与剑数；
- 同时提高单剑灵力总消耗和剑阵压力；
- 不增加剑夹容量。

因此“少量高品质剑”和“多把后备剑轮换”都应当可成立。神识提高必须伴随资源消耗增长，
不能成为没有代价的全局乘区。

## 4. 升级池分层

升级候选按长期职责分为五组。同一候选可以有前置条件，但不得把全部数值集中到一个
超宽“玩家升级组件”。

### 4.1 人物根基

- 神识上限；
- 法力上限与法力恢复；
- 体力上限与体力恢复；
- 剑夹容量；
- 最大生命与基础恢复能力。

### 4.2 御剑术

- 分散攻击间隔；
- 自动索敌范围；
- 返阵速度；
- 单次出剑灵力消耗；
- 后备恢复与轮换阈值。

### 4.3 集火剑诀

- 降低最低启动法力；
- 提高法力到伤害的转换率；
- 提高贯穿收益；
- 缩短集火后的返阵时间；
- 高法力施放时增加有效剑气宽度。

集火始终一次消耗全部当前法力。常规升级不保留施放后的剩余法力，避免破坏爆发与恢复
阶段之间的边界。

### 4.4 剑阵与身剑合一

剑阵升级包括范围、运行速度、维持效率、额外路线和切换后的短时强化。身剑合一升级包括
聚剑时间、体力效率、转向能力、伞面宽度，以及结束时释放散射或前向剑波。

每条路线至少保留一项改变行为的升级，不能全部退化为伤害、速度和冷却倍率。

## 5. 剑意组合

第一阶段继续维持单剑意与战斗方式的明确联动：

| 剑意 | 分散 | 集火 | 剑阵 | 身剑合一 |
| --- | --- | --- | --- | --- |
| 雷 | 独立攻击传播连锁 | 首次贯穿向线外目标连锁 | 暂不强化 | 暂不强化 |
| 金 | 暂不强化 | 后续贯穿目标获得破势 | 暂不强化 | 核心前向扫掠积累破势 |
| 火 | 暂不强化 | 贯穿积累火印 | 高频接触积印并爆发 | 暂不强化 |
| 寒 | 命中叠加寒气 | 暂不强化 | 延长敌人在阵图内停留 | 暂不强化 |

先完成上述单剑意深层联动，再设计火寒、雷金等双剑意反应。二次触发伤害不得递归触发
同类剑意，也不得默认参与吸血。

## 6. 生命恢复分类

“回血”是生命恢复总称，至少区分以下来源：

| 类型 | 触发 | 主要用途 | 必须限制 |
| --- | --- | --- | --- |
| 自然恢复 | 按秒持续 | 脱离高压后的基础续航 | 恢复速率 |
| 吸血 | 造成合格直接伤害 | 战斗中的持续恢复 | 单次、储备和总速率三重上限 |
| 击杀恢复 | 击杀敌人 | 清理普通敌潮的构筑收益 | 单 Tick 上限 |
| 生命掉落物 | 移动拾取 | 战术站位和紧急恢复 | 掉落率与单次恢复量 |
| 直接命中恢复 | 每次命中 | 暂不进入第一阶段 | 必须有 Tick 上限或独立冷却 |

所有恢复最终经过统一的生命恢复请求与结算规则，不能由不同技能直接修改 `Health.Current`。

## 7. 吸血模型

### 7.1 参考与取舍

《流放之路》的吸血通过单次吸血量、单实例恢复速度和所有实例的总恢复速度限制高伤害与
高频命中的恢复爆炸。默认参考值可见
[PoE Wiki 的 Leech 机制说明](https://www.poewiki.net/wiki/Leech)。

本示例借鉴三重限制，但不逐命中长期保存吸血实例。飞剑可能在一个 Tick 内产生大量接触，
逐命中实体会扩大查询和结构迁移规模。示例改用人物 ECS 组件中的聚合吸血储备，明确接受
恢复曲线与 PoE 独立实例不完全相同。

### 7.2 默认参数

| 参数 | 初始建议值 |
| --- | ---: |
| 基础吸血比例 | 0%，由升级或剑器属性获得 |
| 单次命中最大吸血量 | 最大生命的 5% |
| 最大吸血储备 | 最大生命的 40% |
| 储备释放基准时间 | 3.33 秒 |
| 最大总吸血恢复速度 | 每秒最大生命的 12% |

单次命中先计算：

```text
实际合格伤害 =
min(最终合格伤害, 目标结算前的当前生命)

原始吸血量 = 实际合格伤害 × 有效吸血比例

本次加入储备 =
min(原始吸血量, 最大生命 × 单次吸血上限)
```

过量伤害不产生额外吸血。多个伤害事实按确定顺序结算，后续事实只能使用前序扣血后的目标
当前生命，避免对同一低生命敌人重复吸取超过其实际生命的数值。

然后更新人物吸血储备：

```text
吸血储备 =
min(当前储备 + 本次加入储备, 最大生命 × 储备上限)
```

每个固定 Tick 的恢复速度为：

```text
吸血恢复速度 =
min(
    吸血储备 / 储备释放基准时间,
    最大生命 × 最大总吸血恢复比例
)
```

实际恢复不得超过缺失生命；默认到达满血时清空剩余储备，不能把吸血预存为下一次受伤后的
隐形护盾。稀有升级可以允许满血后短暂保留，但必须有独立持续时间上限。

### 7.3 示例

角色最大生命为 100，对一个拥有足够当前生命的目标造成 2000 点最终合格伤害，拥有
1% 吸血：

```text
原始吸血量 = 20
单次命中上限 = 5
最终只向储备加入 5
```

即使多把剑同时命中并填满 40 点储备，每秒最多恢复 12 点生命，不会因剑数或单次伤害
立即回满。

### 7.4 合格伤害

第一阶段只有直接伤害参与吸血：

| 伤害来源 | 是否参与 |
| --- | --- |
| 分散飞剑直接命中 | 是 |
| 集火飞剑贯穿 | 是 |
| 剑阵飞剑接触 | 是 |
| 身剑合一核心与飞剑直接接触 | 是 |
| 雷意连锁 | 否 |
| 火印爆发 | 否 |
| 金意破势追加伤害 | 否 |
| 其他触发型二次伤害 | 否 |
| 持续伤害 | 否 |

单剑吸血词缀只作用于该剑自己的直接伤害。人物全局吸血与来源剑吸血可以相加，但不能把
一把剑的吸血属性复制给整个控制组。

## 8. 其他回血规则

### 8.1 自然恢复

基础可以从每秒最大生命的 0%～0.5% 开始，由“吐纳”等升级提高。自然恢复稳定但缓慢，
不依赖攻击，不应超过专门吸血构筑在战斗中的恢复能力。

### 8.2 击杀恢复

建议普通敌人恢复最大生命的 0.3%～0.5%，精英恢复 2%，并设置每 Tick 最多恢复最大生命
的 5%。剑阵同时击杀大量敌人时，超过 Tick 上限的恢复被舍弃。

### 8.3 生命掉落物

生命灵蕴建议恢复最大生命的 10%～15%，需要玩家移动拾取。它提供与自动吸血不同的战术
目标，使身剑合一可以用于穿越敌群取得紧急恢复。

### 8.4 直接命中恢复

第一阶段不加入“每次命中固定回复生命”。如果后续开放，必须采用每 Tick 总上限、每剑
独立冷却或“对同一目标首次命中”中的至少一种限制。

## 9. ECS 数据边界

建议按职责拆分：

```ts
export enum LifeLeechStats {
    GlobalDamageRatio,
    MaximumPerHitRatio,
    MaximumStoredRatio,
    ReleaseDuration,
    MaximumRecoveryPerSecondRatio,
}

export enum LifeLeechRuntime {
    Stored,
}

export enum LifeRegeneration {
    FlatPerSecond,
    MaximumLifePerSecondRatio,
}

export enum HealingRequest {
    Source,
    Target,
    Amount,
    Kind,
}

export enum HealingKind {
    Regeneration,
    Leech,
    OnKill,
    Pickup,
    Skill,
}
```

单剑可选吸血属性使用独立组件，不加入已有 `SwordAttackType`。直接伤害事实使用可选 Tag
或归因组件声明“允许吸血”和最终受益人物；雷、火、金等二次伤害不拥有该 Tag。伤害完成
后，吸血 System 按命中应用单次上限，再累计到人物 `LifeLeechRuntime.Stored`。

恢复 System 每 Tick 最多为每个受益人产生一次聚合 `HealingRequest`。System 必须先缓存
Chunk 列，不在逐命中或逐实例热循环中创建数组、对象、闭包和 Map。低频获得或失去吸血
能力可以正常使用组件迁移，不用常驻无效字段代替 Archetype。

## 10. 结算顺序与死亡

推荐固定阶段：

```text
结算上一 Tick 已存在的吸血储备和持续恢复
→ 敌人行为与运动
→ 飞剑接触和伤害效果
→ 最终伤害
→ 汇总本 Tick 新产生的吸血储备
→ 死亡判定
```

- 本 Tick 新产生的吸血最早在下一 Tick 恢复生命；
- 当前生命已经为 0 的实体不能通过普通回血或吸血复活；
- 同 Tick 受到致死伤害并造成伤害时，吸血不能撤销死亡；
- 所有恢复都受到最大生命、降低恢复效果和禁止恢复状态约束；
- 实际恢复量与溢出量应作为统计事实保存，但表现只显示实际恢复量。

## 11. 生存构筑候选

首批可以加入：

| 名称 | 效果 |
| --- | --- |
| 血炼·初识 | 直接飞剑伤害的 0.6% 转化为吸血 |
| 血炼·行血 | 缩短吸血储备释放时间，但不提高总恢复上限 |
| 血炼·血海 | 最大总吸血恢复由每秒 12% 提高到 15% |
| 血炼·藏锋 | 提高单次命中吸血上限 |
| 血炼·余脉 | 满血后最多保留 2 秒吸血储备 |
| 吐纳 | 增加自然生命恢复 |
| 杀生 | 击杀敌人恢复生命，仍受 Tick 上限限制 |
| 回春 | 提高生命灵蕴掉落率或恢复效果 |

吸血比例、单次上限、储备释放速度和最大总恢复速度必须作为不同升级维度，不能用一个
“吸血效果提高”同时放大所有乘区。

## 12. 八分钟单局节奏

| 时间 | 主要压力 | 教学目标 |
| --- | --- | --- |
| 0～2 分钟 | 快速但脆弱的敌人 | 分散、灵力耗尽与后备轮换 |
| 2～4 分钟 | 密集推进敌群 | 剑阵范围控制 |
| 4～6 分钟 | 石傀冲锋与剑魇强化 | 身剑合一位移与集火优先级 |
| 6～8 分钟 | 精英密度和混合敌潮提高 | 法力、体力、吸血和后备剑管理 |
| 第 8 分钟 | 赤目剑魇首领 | 综合验证四种方式和构筑 |

首领应通过召唤敌群、蓄力冲锋、直线弱点窗口和强化阶段验证现有系统，不为首领单独创造
一套与局内构筑无关的玩法。首领死亡进入胜利结算，不能继续普通刷怪。

## 13. 推荐实施顺序

1. 完成剑器模板、属性生成、Offer 对比和满剑夹替换。
2. 重构升级池，使剑夹、神识、法力、灵力与四种方式形成构筑。
3. 实现统一回血请求、自然恢复和聚合吸血储备。
4. 加入精英飞剑奖励与生命灵蕴。
5. 完成八分钟敌潮、赤目剑魇首领和胜利结算。
6. 增加无头完整局、固定 seed 重放和性能基准。

本文通过评审前，不开始实现双剑意反应、局外成长和复杂锻造。
