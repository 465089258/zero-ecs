# 飞剑像素素材

本目录的四张 PNG 由内置图像生成工具生成，并通过色键移除转换为透明背景。

`*-render.png` 是示例运行时实际加载的 128 像素宽裁剪版本。高分辨率原图只作为素材源
保留，不进入浏览器产物。黑色 Alpha 阴影和带光晕的颜色变体在图片加载后一次性生成，
稳定帧不再对高分辨率原图缩放，也不执行 Canvas `filter` 或 `shadowBlur`。

统一规范：

- 中式修仙飞剑、硬边像素风格。
- 剑柄向左、剑尖向右。
- 单剑、完整轮廓、无场景和文字。
- Canvas 根据投影后的飞行方向旋转素材。
- 阴影复用同一素材的 Alpha 轮廓，以黑色半透明方式绘制。
- 透视缩短只作用于剑身轴，素材厚度不随飞剑转向缩放。
- `imageSmoothingEnabled = false`，保持像素边缘。

剑型：

- `sword-jade.png`：青玉灵剑。
- `sword-flame.png`：赤金火剑。
- `sword-frost.png`：寒铁冰剑。
- `sword-thunder.png`：紫电雷剑。

生成提示词统一要求单把中式剑、像素艺术、有限色板、水平朝右、纯色色键背景；每张素材
分别指定青玉、赤金火焰、寒铁冰霜、紫电雷纹的材质和纹样。
