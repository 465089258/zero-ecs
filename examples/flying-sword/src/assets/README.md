# 飞剑肉鸽角色素材

本目录的角色与怪物 PNG 由内置图像生成工具生成，经洋红色色键移除后转换为透明背景。
高清文件作为素材母版保留，`*-render.png` 是按示例显示尺寸预缩放的 Pixi 运行时纹理。

## 使用规范

- 素材采用角色后上方约 55 度的三分之四俯视视角，与示例相机方向一致。
- 主角默认朝向画面右上方，怪物默认朝向画面左下方，适合首版相向交战展示。
- 首版可以按目标位于实体左侧或右侧进行水平镜像，但不要把人形素材绕屏幕法线连续旋转。
- 人形实体以脚底中央作为世界坐标锚点；妖蚀蝠没有地面接触点，以图像中央作为锚点。
- 图片不包含烘焙阴影。地面阴影应由表现层根据实体高度独立绘制。
- Pixi 加载 `*-render.png` 并使用 nearest 缩放模式；不要在稳定帧缩放 1254 × 1254 的素材母版。
- 当前素材是单方向静态原型。需要完整移动表现时，应继续生成四方向或八方向动画图集。

## 生成提示词摘要

统一提示词要求单个完整主体、中式修仙 16-bit 像素风、有限色板、清晰像素块、约 55 度
三分之四俯视视角、纯 `#ff00ff` 色键背景，并禁止场景、文字、投影、光晕和水印。

各素材分别追加以下主体约束：

- 御剑修士：白色与浅青玉汉服、束发、无手持武器。
- 妖蚀蝠：炭黑躯体、暗红翼膜、青色蚀变眼睛。
- 腐骨傀：旧骨、破损丧服、额头封印符、无血腥表现。
- 镇山石傀：深色板岩、宽肩巨拳、胸前琥珀封印纹。
- 剑魇精英：黑蓝破损古袍、青色灵裂、青铜面具和一把断剑。
